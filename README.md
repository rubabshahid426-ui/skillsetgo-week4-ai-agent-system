# Week 4 AI Agent System — Skill Set Go EduTech

Covers the four Week 4 roadmap tasks:
- **4.1 RAG Application:** retrieve relevant passages from uploaded PDF/TXT documents.
- **4.2 Multi-Step Workflow:** LangGraph workflow with classify, retrieve, and respond nodes.
- **4.3 LangSmith Observability:** setup checklist and evaluation log template.
- **4.4 Capstone AI Agent:** demo combining knowledge retrieval, calculator tool, and multi-step routing.

## Setup (VS Code / Windows)
1. Extract this ZIP and open the folder in VS Code.
2. `python -m venv .venv`
3. `.venv\Scripts\activate`
4. `pip install -r requirements.txt`

Run RAG: `streamlit run 01_RAG_Application/app.py`
Run workflow: `python 02_LangGraph_Workflow/workflow.py`
Run capstone: `streamlit run 04_AI_Agent_Capstone/app.py`

Some integrations are demonstration versions. LangSmith tracing requires your own account/API key. Run the tasks and fill reports with actual results before submitting.
